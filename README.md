# 📸 Capture Beauty — 캡처 뷰티

화면 캡처를 **예쁘게** 만드는 브라우저 도구입니다.
캡처 → 필터/AI 보정 → 스탬프 → 배경 꾸미기 → 저장까지 한 곳에서 끝납니다.

**UI 는 두 모드로 구성됩니다.**

1. **캡처 모드 (기본)** — 사진기처럼 온스크린: 뷰파인더 + 가운데 셔터 버튼. 셔터를 누르면
   화면·창·탭을 캡처하고(플래시 효과), 찍은 사진을 바로 리뷰하며 편집/저장/복사를 선택합니다.
2. **편집·설정 모드** — "편집"을 누르면 **프로그램 창**이 떠오릅니다: 신호등 버튼(닫기/최소화/최대화),
   타이틀바 드래그로 이동, 그 안에 필터·AI·스탬프·배경·설정 패널이 들어 있습니다. `Esc` 또는
   빨간 버튼으로 닫으면 캡처 화면으로 돌아갑니다.

| 기능 | 설명 |
|---|---|
| ⚡ **퀵 캡처** | 연속 캡처(선택창 1회 이후 즉시 촬영) + PiP 위젯 + 캡처 후 자동 복사/저장 + 플로팅 썸네일 |
| 🖃 **스탬프** | 날짜/시간 스탬프, 승인·확인 **도장**, 배지, 워터마크, 이모지 — 드래그로 배치 |
| ⌨️ **단축키 설정** | 항목 클릭 → 키 입력만으로 재할당. 충돌 시 자동 이관, localStorage 저장 |
| ✨ **AI 필터** | 특정 필터를 선택하면 Claude API 가 이미지를 분석해 그 이미지에 맞는 보정을 적용 |
| 🖼️ **배경 필터** | 사진 **밖** 영역 처리 — 창 밖 여백 자동 제거, 그라데이션 배경, 자동 비율(16:9 등) |

## 시작하기

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm test         # 단위 테스트 (vitest)
npm run e2e      # 브라우저 스모크 테스트 (build 후 실행)
```

이미지는 세 가지 방법으로 불러옵니다.

- **🔴 셔터 (화면 캡처)** — 브라우저의 화면 공유 API 로 모니터/창/탭을 캡처
- **📋 붙여넣기** — `Ctrl+V` 또는 셔터 옆 클립보드 버튼
- **📂 열기 / 드래그&드롭** — 이미지 파일

## ⚡ 퀵 캡처 — 창 안 띄우고 바로

Win+Shift+S(윈도우) / Cmd+Shift+5(맥) / ShareX·CleanShot·Snagit 의 "즉시성" 패턴을
웹 제약 안에서 재현했습니다. 설계 문서: [docs/quick-capture.md](docs/quick-capture.md)

- **🔗 연속 캡처** — 화면을 한 번만 연결하면 스트림을 유지, 이후 셔터는 **선택창 없이 즉시** 촬영
  (LIVE 배지 표시, 브라우저의 "공유 중지"로 언제든 해제)
- **🧷 PiP 위젯** — 모든 앱 위에 항상 떠 있는 초소형 리모컨(Chrome 116+).
  탭을 최소화해도 위젯의 셔터만으로 [촬영 → 자동 복사]가 끝납니다
- **캡처 후 자동 동작** (설정 탭) — 자동 여백 제거 / 클립보드 복사 / 파일 저장 토글
- **플로팅 썸네일** — macOS 스타일로 우하단에 잠깐 표시, 클릭하면 그때만 편집 창이 열립니다

## 🖥️ 데스크톱 앱 (Electron)

웹에서 불가능한 마지막 조각까지 — **전역 단축키 · 트레이 · 완전 무선택창 캡처**:

```bash
npm run build && npm run desktop      # 검증: npm run e2e:desktop (리눅스 헤드리스: xvfb-run -a 붙여서)
```

- **전역 단축키** — 기본 `Ctrl/Cmd+Shift+1` 빠른 캡처(창을 띄우지 않고 촬영→자동 복사→알림),
  `Ctrl/Cmd+Shift+2` 캡처 후 편집 창. 설정 탭 "전역 단축키"에서 변경, 영구 저장
- **트레이 아이콘** — 빠른 캡처/캡처 후 편집/창 열기/종료. 창 닫기는 종료가 아니라 트레이로
- **무선택창 캡처** — `desktopCapturer` 가 주 화면을 바로 뜨고, 캡처 직전 자기 창을 자동으로 숨겼다 복원.
  연속 캡처(getDisplayMedia)도 자동 승인되어 선택창이 아예 없음
- **OS 클립보드 직접 복사** — 창 포커스 없이도(백그라운드 캡처) 복사 완료

## 스탬프

스탬프 탭에서 원클릭 프리셋을 제공합니다.

- 📅 날짜 / ⏰ 날짜+시간 — 타임스탬프 카메라 스타일, 형식 선택 가능 (`YYYY-MM-DD`, `YYYY년 MM월 DD일`, 요일 `ddd` 등)
- 🔴 승인 / ✔️ 확인 — 원형 이중 링 **도장** 스타일
- 🏷️ 대외비 배지, 📝 DRAFT 워터마크, ⭐ 이모지, ✏️ 자유 텍스트

추가한 스탬프는 미리보기에서 **드래그로 이동**, 사이드바에서 크기·회전·불투명도·색상·스타일(기본/배지/도장/외곽선/리본)을 조정합니다. `Del` 로 삭제.

## 단축키

설정 탭에서 단축키 항목을 **클릭한 뒤 원하는 키를 누르면** 바로 설정됩니다 (`Esc` 취소, `✕` 해제).
이미 다른 기능이 쓰는 조합을 누르면 그 기능에서 자동으로 가져오고 알려줍니다.

기본값: `Ctrl+Shift+S` 캡처 · `C` 연속 캡처 연결/해제 · `P` 위젯 · `E` 편집 창 열기/닫기 · `Ctrl+E` 저장 · `Ctrl+Shift+C` 복사 · `A` AI 보정 · `T` 날짜 스탬프 · `D` 도장 · `R` 비율 순환 · `W` 여백 제거 · `1~5` 탭 전환

## AI 필터 (Claude API)

AI 탭의 필터(✨ 자동 보정 / 🌈 생생하게 / 🎬 시네마틱 / 🌅 감성 무드 / 📄 문서 최적화)를 선택하면:

1. 이미지를 축소(≤1024px)해 **Claude API** (`claude-opus-5`, 비전 + 구조화 출력)로 전송
2. 그 이미지에 맞는 보정 파라미터(밝기·대비·채도·색온도·선명도 등)를 JSON 으로 수신
3. 로컬 필터 엔진이 원본 해상도에 적용 — 보정 이유 코멘트도 표시

자유 입력("새벽 감성으로 차갑게" 등)도 지원합니다.

- **API 키**: 설정 탭에 Anthropic API 키를 입력하세요. 키는 **이 브라우저의 localStorage 에만** 저장되며 Anthropic API 외 어디에도 전송되지 않습니다.
- **안전 폴백**: 서버측 refusal fallback(`fallbacks: "default"`)이 켜져 있어, 정책상 거절되는 요청은 같은 호출 안에서 대체 모델로 자동 재시도됩니다.

### 외부 변환 API (선택)

배경 제거·스타일 변환처럼 **픽셀 자체를 바꾸는** 자체 서버가 있다면 설정 탭에 URL 을 등록하세요. 계약은 단순합니다.

```
POST <URL>            Content-Type: application/json
{ "image": "data:image/png;base64,...", "instruction": "배경 제거" }
→ 200 { "image": "data:image/png;base64,..." }
```

변환 결과는 원본을 교체하며 ↩️ 실행 취소로 되돌릴 수 있습니다.

## 배경 필터 (사진 밖 자동 보정)

배경 탭의 **스마트 배경 필터** 는 하나만 눌러도 아래를 한 번에 세팅합니다.

- 🪟 **창 캡처 정리** — 창 밖 균일 여백 자동 감지·제거 + 그림자/둥근 모서리
- 🖥️ **프레젠테이션** — 자동 16:9 비율 + 그라데이션
- 📷 **인스타 정방형** (1:1) · 📱 **스토리** (9:16) · 📄 **문서 첨부용** (4:3)

수동 조정: 배경 12종(그라데이션/메시/그리드/도트/단색…), 비율(자동·16:9·4:3·3:2·1:1·9:16), 여백·모서리·그림자 슬라이더, ✂️ 자동 여백 제거.

## 구조

```
src/
├── main.ts        UI 배선 · 캡처(카메라)/편집(창) 모드 전환 · 창 드래그 ·
│                  미리보기(축소본)/내보내기(원본 해상도) 분리
├── filters.ts     픽셀 필터 엔진 (밝기/대비/채도/색온도/샤픈/블러/비네트/그레인…)
├── stamps.ts      스탬프 모델 · 날짜 형식 · 도장/배지/리본 렌더링
├── background.ts  자동 트림 감지 · 비율 레이아웃 · 배경 프리셋 · 스마트 필터
├── quickcapture.ts 연속 캡처 세션(스트림 유지 → 즉시 프레임) · 퀵 동작 설정
├── widget.ts      PiP 캡처 위젯 (Document Picture-in-Picture)
├── shortcuts.ts   단축키 매니저 (녹화식 할당 · 충돌 자동 이관 · 직렬화)
├── ai.ts          Claude API 연동 (vision + zod 구조화 출력 + refusal fallback)
├── render.ts      합성 파이프라인 (필터 캐시 → 배경 → 그림자 → 스탬프)
├── capture.ts     getDisplayMedia · 클립보드 · 파일 로더
├── exporter.ts    PNG/JPG/WebP 저장 · 클립보드 복사 · 분석용 다운스케일
└── settings.ts    localStorage 설정 저장

desktop/
├── main.cjs       Electron 메인 — 트레이 · 전역 단축키 · desktopCapturer · 창 숨김/복원
├── preload.cjs    contextBridge → window.native (렌더러 타입: src/native.ts)
└── config.cjs     accelerator 검증/정규화 (단위 테스트 대상)

tests/                     vitest 단위 테스트 — DOM 없이 순수 로직 검증
scripts/e2e.mjs            Playwright 스모크 테스트 — 실제 Chromium 에서 웹 전체 플로우 검증
scripts/e2e-desktop.mjs    Playwright _electron — 실제 Electron 에서 데스크톱 기능 검증
```

## 브라우저 지원

Chromium 계열 권장 (화면 캡처 `getDisplayMedia`, 클립보드 이미지 API 기준).
AI 필터는 브라우저에서 직접 Anthropic API 를 호출하므로 개인 도구/내부 도구 용도에 적합합니다.
서비스로 배포한다면 API 키를 노출하지 않도록 서버 프록시를 두세요.
